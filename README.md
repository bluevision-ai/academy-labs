# Bluevision AI Academy — Labs

Free, self-contained Colab notebooks that go with the [Bluevision AI](https://www.youtube.com/@BlueVision-AI) YouTube channel — hands-on companions to Vahid Seydi's lectures on machine learning and AI, from [Bluevision AI Academy](https://bluevision-ai.org), the education arm of Bluevision AI.

Our goal is to help you become a creator of AI, not simply a user: every lecture's notebook lets you code the idea yourself.

Notebooks are pushed here as soon as each session is ready, independent of when the matching video is published. Open a notebook directly in Colab, no setup required.

## Structure

One folder per course, one subfolder per session:

```
<course>/<session-slug-or-number>/<session>_lab.ipynb
```

For example, a standalone single-topic session:

```
ml-foundations/retrieval/retrieval_lab.ipynb
```

and a numbered course session:

```
LLM/session01/session01_lab.ipynb
```

## Citing this work

Every lecture is a section of a free companion book. Cite the **book**, or the chapter you
used, not the video and not the notebook (unless you are specifically citing the code). The
reference that is correct today is always on the book page:

- *Large Language Models: How They Grew, One Problem at a Time*: <https://books.bluevision-ai.org/LLM/>
- *Machine Learning: A Modelling Perspective*: <https://books.bluevision-ai.org/ml-foundations/>

GitHub's "Cite this repository" button (from [`CITATION.cff`](CITATION.cff)) gives the notebook
citation in APA and BibTeX.
